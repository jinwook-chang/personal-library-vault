# 허무주의

## Definition

허무주의는 기존 가치와 의미의 근거가 설득력을 잃었을 때 발생하는 가치 공백의 상태를 뜻한다.

## In This Library

[[Books/차라투스트라는 이렇게 말했다|차라투스트라는 이렇게 말했다]]는 허무주의를 단순한 절망이 아니라 새로운 가치 창조의 문제로 전환한다. [[Books/선악의 저편|선악의 저편]]은 이 전환을 도덕과 철학의 전제 비판으로 밀고 가며, 기존 선/악 도식이 더 이상 자명하지 않다는 점을 드러낸다.

## Nuances

니체에게 허무주의는 단지 “아무 의미도 없다”는 결론이 아니라, 기존 가치 체계가 더 이상 삶을 지탱하지 못하는 역사적·심리적 조건이다.
