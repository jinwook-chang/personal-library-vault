# 합리적 낙관주의

## Definition

합리적 낙관주의는 인간 사회가 교환, 전문화, 과학, 제도를 통해 장기적으로 문제를 해결하고 번영을 확장해왔다는 데이터 기반의 낙관적 관점이다.

## In This Library

[[Books/이성적 낙관주의자|이성적 낙관주의자]]가 이 개념의 중심 텍스트다. [[Books/도시의 승리|도시의 승리]]와 [[Books/더 박스|더 박스]]는 낙관주의의 공간적·물류적 조건을 보여준다.

## Nuances

합리적 낙관주의는 모든 문제가 자동 해결된다는 낙천주의가 아니다. 어떤 제도와 기술이 문제 해결 능력을 높였는지 따져야 한다.
